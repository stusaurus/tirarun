# ティラクリ

ティラノンが走り続ける、スマホ向けワンタップ・エンドレスランゲームです。

公開URL: https://stusaurus.github.io/tirarun/

## 現在のゲーム要素

- 左右移動なしの自動スクロール
- タップでジャンプ、空中でもう一度タップで2段ジャンプ
- 栗を避けてスコア更新
- 段差・足場パターン
- `TIRAKURI` の文字を順番に集めると8秒間FEVER（スコア3倍・栗を破壊）
- シールド / マグネット / 巨大化アイテム
- 走行距離で背景が切り替わる
- BESTスコアを端末に保存

## 構成

- `index.html` UI
- `style.css` レイアウト・見た目
- `game.js` ゲームロジック

今後は実際のプレイ感を見ながら、速度・障害物間隔・ジャンプ感・アイテム出現率・ティラノンの見た目を調整します。
